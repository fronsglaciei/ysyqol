# [Yog-Sothoth's Yard QoL Mod](https://github.com/fronsglaciei/ysyqol/releases)

**Yog-Sothoth's Yard** steam版に細かな機能を追加するMODのリポジトリです.

Unity汎用Moddingフレームワークの**BepInEx**のプラグインとして作成しています.

[非公式日本語化MOD](https://github.com/fronsglaciei/ysytrans)の翻訳作業中に, ゲームプレイを補助するために作成したMODのコードを整理し, 公開用にまとめたものです. 公式日本語翻訳の実装に伴い, 非公式日本語化MODはアーカイブ化し, 当MODにおまけ機能として統合されました.

## 動作環境

当MODの最新版は以下の環境で作成および動作確認しています.

* Yog-Sothoth's Yard - steam 26/07/22 update
* BepInEx IL2CPP 6.0.0-pre.2
* Windows 11
